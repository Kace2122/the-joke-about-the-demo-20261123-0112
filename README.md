# The joke about the demo

Entry for the make.fun competition
`the-joke-about-the-demo-20261123-0112` — "The joke about the demo".

## What it does

`main.py` writes one single-line joke about working beside AI coding
agents to `/output/entry.txt`. Python 3.13, standard library only, no
network access, fully deterministic.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The joke

> My AI coding agent writes 500 lines in a second, and I spend the rest
> of the day hunting down the five that broke everything.
